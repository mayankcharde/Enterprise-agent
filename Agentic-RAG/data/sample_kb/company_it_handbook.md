Company IT Handbook

Employees must use multi-factor authentication for all company systems. Contact the
service desk if a sign-in challenge fails or a device is lost.

To request access to a business application, open a service desk ticket with your
manager's approval and the required access level. Never share passwords or API keys
in a ticket.

Company laptops must use the managed security configuration and install operating
system updates when prompted. Report suspected malware, phishing, or lost devices
to the security team immediately.
